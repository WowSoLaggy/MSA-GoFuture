# Задание 1. Проектируем домены

Монолитная архитектура «GoFuture» тормозит развитие бизнеса, поэтому компании нужно осуществить переход к микросервисам. Разработайте поэтапный план декомпозиции на доменные сервисы, соответствующие продуктовым командам, с минимизацией времени простоя.

**Поэтапный план декомпозиции на год состоит из нескольких этапов:**

1. Первый этап — проработка нефункциональных требований.
2. Далее формируется карта сервисов с чёткими доменными границами.
3. На следующем шаге определите приоритетную очерёдность выделения сервисов.
4. Создайте схему To-Be уровня C2.
5. На пятом этапе разрабатываются механизмы обеспечения обратной совместимости.
6. Завершающий этап — план миграции данных для каждого сервиса, учитывая большой объём данных.

**В результате у вас должно получиться:**

1. Список нефункциональных требований.
2. Диаграмма С2 сервисов To-Be с механизмом обеспечения обратной совместимости.
3. Описание очерёдности выделения сервисов с обоснованием логики.
4. План миграции.
