# Обеспечение качества данных

## Контракты и схемы событий

- Для каждого типа события фиксируется json / proto схема
- Схемы версионируются с обратной совместимостью

## Уникальность и идемпотентность

- В каждом событии обазятельно `event_id`
- При обработке дедуп по `event_id`
- Запись в ClickHouse идемпотентная

## Валидация ивентов

- Ивенты валидируются:
  - обязательные поля (event_id, timestamp, region, ...)
  - диапазоны (цена > 0, ...)
  - типы данных (цена не может быть строкой, ...)

## Архив ивентов

- Все входные события сохраняются в файловое хранилище, чтоб можно было проводить аудиты, дополнительные сверки
