# Подход к Мониторингу

Основные метрики для мониторинга: задержки, ошибки и нагрузка. Для дебаггинга связываем события через `trace_id`.

## Инструменты

- Prometheus - метрики
- Grafana - дашборды
- Alertmanager - алерты
- Loki - логи

## Основные метрики

Уровень бизнеса (каждая метрика по регионам):

- `trips_total` - общее число поездок пассажиров - главная статья прибыли
- `active_users_total` - число активных пользователей - показатель роста, потенциальная прибыль
- `drivers_online_total` - число доступных водителей - влияет на время ожидания
- `trip_wait_time` - время ожидания пассажиром от заказа до начала поездки - большое влияние на удовлетворённость клиентов

Уровень инфраструктуры (по сервисам / топикам):
- `http_5xx_total` - количество ошибок 5xx - показатель стабильности сервиса
- `events_processed_total` - количество обработанных событий - нагрузка на систему
- `event_handler_duration_seconds_p95` - время обработки события (95-й перцентиль) - производительность
- `kafka_consumer_group_lag` - отставание консумер-группы - показатель своевременности обработки событий
- `dlq_messages_total` - количество сообщений в DLQ - показатель проблем с обработкой событий
